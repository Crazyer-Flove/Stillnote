# 隐私与数据说明

Stillnote 默认将笔记保存在本机，不要求账号，不提供内置云同步或笔记分析服务。桌面版加载打包的前端资源，默认不启动网络服务。

本地优先不代表完全没有网络访问：笔记中的外链图片、网页预览和外部链接会访问对应第三方站点；这些站点可能获知请求信息。离线时相关资源可能不可用。应用不应被当作加密保险箱，本地配置没有额外应用层加密。

JSON 备份由用户主动导出，包含笔记、历史、引用的本机图片、工作区和允许的偏好；工作区路径描述也可能在备份中。不要将真实备份上传到公开 Issues。独立资源库、文件夹授权、API Key、搜索记录及导出偏好不纳入完整备份。

文件夹写入需要用户主动选择目录。桌面快捷方式也由用户在设置中主动创建，不会上传笔记。应用内部诊断只在指定的独立目录写入结果与测试配置，不记录笔记正文。

发布包和本机使用数据分离。删除浏览器站点数据或系统用户配置可能丢失笔记；卸载默认保留桌面配置。请定期导出并验证备份。
