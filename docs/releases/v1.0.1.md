Stillnote 1.0.1 · 最终发行检查补丁。

包含 1.0.0 的全部功能与全新界面，以及 Windows 便携版、可选择目录的安装版和设置中的桌面快捷方式按钮。

此次补丁移除旧内联 fetch 修改脚本，修正 Electron 新版控制台事件的诊断参数，并确保重复打包时清除过期前端资源，显式排除不需要的 Node 依赖，应用资源归档约 4 MB。发布流程会先通过类型检查、24 项测试及实际 EXE 启动诊断，再上传文件。

- `Portable.exe`：免安装，直接双击使用。
- `Setup.exe`：安装到指定位置，创建开始菜单入口。
- `SHA256SUMS.txt`：校验下载文件。

Windows 10/11 x64。当前 EXE 未签名，请从本仓库下载并核对 SHA-256。

两种版本共用 `%APPDATA%\Stillnote` 数据目录。便携版数据不保存在 EXE 旁边。在「系统设置 → 外观」主动创建桌面快捷方式；移动便携 EXE 后请重新创建。

旧版和网页数据通过 JSON 备份导出/导入迁移，不会自动与桌面版共享。迁移前先保留原备份，导入前检查预览。详见仓库 README 与使用指南。
