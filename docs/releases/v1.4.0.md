# Stillnote 1.4.0

- 统一编辑器、设置、内容导出与备份预览的中性色、按钮、表单与面板层次。
- 修正旧 Tailwind 配色令牌残留的橄榄色，简化编辑器嵌套画布边框。
- 低窗口高度时工具栏横向滚动，保存和关闭操作保持独立；移动端导出按钮使用紧凑短文案。
- 代码块编辑器移除装饰圆点，保留语言选择、代码输入和完成操作。
- 主界面和完整编辑器新增 2 倍局部放大镜，支持鼠标、触摸和方向键，按 Esc 退出。
- 保留三种导出卡片主题、Markdown、图片/PDF、原生目录存储和备份功能。

Windows 10/11 x64。当前 EXE 未签名，请核验 SHA256SUMS.txt。便携版数据仍保存在 %APPDATA%\Stillnote；旧快捷方式可在新版设置中重新创建。
