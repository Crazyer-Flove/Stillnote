Stillnote 1.0.0：原 FloveNote 的新名称与首个 Windows 桌面版本。

- 重新整理界面与设置，保留 Markdown 编写、搜索、标签、工作区、备份和导出。
- 精简卡片主题、阅读字体和代码样式；支持模板、批量处理与会话历史对比。
- 修复草稿初始化、输入区域撤销/重做冲突和对话框焦点。
- Windows 便携版直接双击使用；安装版支持选择目录与开始菜单入口。
- 在「系统设置 → 外观」中主动创建桌面快捷方式。

下载 `Portable.exe` 免安装运行，或 `Setup.exe` 安装。两者均为 Windows 10/11 x64；数据共用 `%APPDATA%\Stillnote`，不保存在便携 EXE 旁边。

从网页或旧版迁移：在原环境导出 JSON，再在新版备份恢复中导入。请先保留原备份；独立资源库、目录授权、搜索和导出偏好不在完整备份内。

当前 EXE 未签名，请从本仓库下载并按 `SHA256SUMS.txt` 核验文件。类型检查、24 项测试和便携 EXE 启动诊断通过；未覆盖全部 Windows 版本与硬件。更多说明见仓库 README 与 docs/user-guide.md。
