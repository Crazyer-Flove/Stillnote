# Stillnote 1.2.1

- 首次使用仅保留默认工作区，允许创建和删除自建工作区；删除时将笔记与回收站记录移入默认工作区，磁盘文件保留。
- 旧版内置“工作与项目、研习与灵感”安全合并回默认工作区，自建工作区保留。
- Windows 原生文件夹选择，显示真实路径并在重启后记住。选择一个根目录后统一生成 Notes、Images、Backups。
- 本机图片独立落盘、相对引用和扫描导入恢复；JSON 快照仍内嵌图片。
- 移除标签入口、交互和筛选；正文中的 #文字 保留。
- 侧边栏常驻展开/收起按钮，支持拖动调宽和状态记忆。
- 改进响应式布局；桌面 Ctrl +/- 缩放、Ctrl 0 重置，代码和表格局部滚动。

建议升级前导出 JSON。Windows 10/11 x64；便携版直接运行，安装版支持选择位置。应用数据仍在 %APPDATA%\Stillnote，便携版不是随 EXE 搬移数据的模式。

当前 EXE 未签名，请核对 SHA256SUMS.txt。类型检查、回归测试和实际 EXE 启动诊断在发布前执行。网页版同步更新：https://stillnote-crazyer.vercel.app

发布补丁修正 Windows 短路径别名下的目录测试比较，不改变已选目录的权限范围。
