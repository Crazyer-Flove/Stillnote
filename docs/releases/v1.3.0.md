# Stillnote 1.3.0

- 修复折叠按钮压住品牌标志，折叠栏顶部仅显示展开按钮。
- 工作区与工具菜单移入独立弹层，不再被侧边栏裁切；自动避让窗口边界，支持键盘焦点、Esc 与外部点击关闭。
- 窗口跨入移动布局时关闭隐藏锚点的弹层，避免悬空菜单。
- 参考 Codex 的中性色、紧凑导航、系统字体标题和轻量面板层次，更新主界面与控件。
- 保留工作区、原生文件夹存储、Markdown 写作、导出和备份功能，数据目录保持不变。
