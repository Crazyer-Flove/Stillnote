# Stillnote 使用与迁移指南

## 第一次使用

1. 在首页输入想法，点击「记下」。需要长文、代码或表格时打开完整编辑器。
2. 使用 `#标签` 整理内容，侧边栏可查看标签、收藏和置顶。
3. 工作区用于分开不同用途的笔记；搜索、筛选和批量操作以当前工作区为范围。
4. 在设置中选择阅读字体、明暗模式和自动保存偏好。
5. 写下第一批内容后，到「备份恢复」下载 JSON 备份，并确认文件确实保存成功。

## 编辑与历史

已有笔记可自动保存，顶部保存状态反映本机保存结果。新建笔记和模板先作为草稿，点击保存后进入笔记库。编辑器支持 Markdown 源码、即时预览、分栏和预览模式；工具栏提供常用格式，表格与公式等在更多格式中。

每次打开已有笔记进行修改，会保留这次编辑的起始版本，连续自动保存不会生成大量重复快照。每篇最多保留 50 个快照。历史窗口可以查看差异并恢复内容；它不是永久版本控制或独立备份。

## 搜索与批量处理

搜索覆盖笔记正文和标签，可组合日期与其他筛选条件。最近搜索和命名筛选保存在当前应用配置中。清空搜索历史不会删除笔记。

批量选择只针对当前结果。添加标签会更新正文中的标签，移动时选择目标工作区，删除先进入回收站。永久删除和清空回收站不可撤销，请先备份。回收站保存期限以应用内提示为准。

## 内容导出与备份的区别

| 目标 | 推荐格式 | 说明 |
| --- | --- | --- |
| 到其他 Markdown 工具继续写 | Markdown | 可读、便于编辑，不是完整应用备份 |
| 分享到社交平台 | PNG 卡片 | 三种主题，高级参数可调整尺寸与显示项 |
| 阅读或打印 | PDF | 以图片排版，不提供可搜索正文层 |
| 恢复或迁移整个笔记库 | JSON | 包含历史和工作区，导入前有预览 |

复制图片依赖剪贴板权限；如不可用，请下载 PNG。远程图片的跨域限制、加载失败或超长内容会影响图像导出，请先检查预览。JSON 下载提示仅表示已发起下载，请检查下载目录。

## 从 FloveNote、网页或另一台电脑迁移

1. 在原来的浏览器、域名和端口打开旧版，导出 JSON 备份。不要先清除站点数据。
2. 在 Stillnote 打开「设置 → 备份恢复」，选择备份文件。
3. 检查笔记数量、重复和 ID 冲突，选择导入当前工作区或恢复原工作区结构。
4. 确认后导入，抽查正文、图片、标签和历史，再另外保存一份新版备份。

重复内容可跳过；ID 冲突可复制为新笔记。导入采用合并方式，不要求清空现有库。旧主题参数会映射到当前支持的样式，原笔记正文不因此改写。

备份包含笔记引用的本机图片，但不包含独立资源库中未纳入笔记的图片，也不包含文件夹授权、API Key、搜索记录、命名筛选和导出偏好。外链图片仍需原服务器可访问。

## Windows 版

便携版双击运行；安装版提供目录选择和开始菜单入口。「设置 → 外观 → 创建桌面快捷方式」由用户主动执行，可重复创建。便携 EXE 移动后需要重新创建快捷方式。

两种版本都使用 `%APPDATA%\Stillnote` 保存数据，便携版不是随 U 盘移动数据的模式。卸载默认保留应用数据。请通过 JSON 迁移，不要在应用运行时复制或替换内部数据库文件。

关闭应用后重新打开，会读取同一用户配置。浏览器与桌面版不会自动共享数据；重装 Windows、清理用户配置、换用户账户前务必备份。

## 文件夹存储

文件夹写入是可选功能。首次使用时选择目录并授予访问权限；设置中的路径描述本身不会授予权限。重新启动或权限过期后可能需要再次选择。

先查看预览再写入。系统对已有笔记文件进行内容和归属检查；不属于本应用的同名文件、预览后被外部修改的文件会被保护。文件夹写入和导入不是实时双向同步，不应同时在多个程序中编辑同一文件后假定自动合并。

## 常见问题

- **看不到旧笔记？** 先检查是否换了工作区、浏览器、端口或桌面版；在原环境导出 JSON 再导入。
- **保存失败？** 暂停继续编辑，导出当前内容或备份；检查磁盘空间、浏览器容量和目录权限。
- **图片离线不显示？** 外链图片依赖网络。对需要长期保存的图片使用本机图片，并验证 JSON 备份恢复。
- **EXE 被提示来源未知？** 当前版本未签名。先核对仓库、文件名和 SHA-256；不要运行来源不明的修改版。
