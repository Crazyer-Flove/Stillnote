# Stillnote 使用指南

## 写作与整理

首页快速输入后点击“记下”；完整编辑器提供 Markdown、代码、表格和公式。已有笔记可自动保存，新建笔记与模板先保留为草稿，明确保存后进入笔记库。

首次使用只有默认工作区。左侧工作区菜单中进入管理，可以添加工作区。删除自建工作区会将其中笔记与回收站记录移入默认工作区，默认工作区不能删除。旧版两个内置示例工作区升级时会合并回默认工作区，自建工作区不变。

标签功能已移除。正文中的 #文字 作为普通内容保留；可通过工作区、收藏、置顶、日期和全文搜索整理笔记。

## 文件夹存储

进入「系统设置 → 文件夹存储」，选择一个根目录。桌面版使用 Windows 原生目录选择器，显示实际绝对路径，并记住每个工作区的选择。重新打开应用后路径仍可用；移动、删除目标目录或外接磁盘离线时需要重新选择。

网页版使用浏览器目录授权，不能通过输入绝对路径获得权限，重新打开后可能需要再次授权。未支持此接口的浏览器仍可使用下载导出。

一个根目录下统一使用 Notes、Images、Backups，不再分别配置路径。点击“预览并写入文件夹”，检查文件列表后确认；先写 JSON 快照，再写本机图片和 Markdown。JSON 内嵌图片，Markdown 引用 Images 中的相对路径。扫描导入 Markdown 时会将应用生成的图片相对路径还原为可移植图片。

此功能不是实时双向同步。应用不会自动删除旧目录里的文件，文件冲突和外部修改会阻止覆盖。删除应用中的工作区不会删除磁盘目录。远程图片保持外链，不自动离线缓存。

## 侧边栏与窗口

点击品牌旁的按钮展开或收起导航。拖动展开状态的右边缘可调宽；也可用 Tab 聚焦“调整侧边栏宽度”，按左右方向键调整。状态保存在本机。

桌面版 Ctrl + 放大、Ctrl - 缩小、Ctrl 0 重置。窄窗口使用移动导航。正文自动换行，表格和代码局部滚动，避免挤压整页。

## 历史、导出与备份

每次编辑会话保留起始版本，最多 50 个历史快照，可查看变化并恢复。历史不是独立备份。

Markdown 用于继续编辑；PNG 卡片与 PDF 用于分享，PDF 为图像排版；JSON 用于恢复和迁移整个笔记库。复制图片依赖剪贴板权限，失败时可下载 PNG。

JSON 包含笔记、历史、引用的本机图片、工作区及允许的偏好，不含独立资源库、文件夹授权、API Key、搜索记录或导出参数。下载提示表示已发起下载，请检查实际文件。

## Windows 与网页数据迁移

桌面版数据位于 %APPDATA%\Stillnote，便携版与安装版共用目录。便携版数据不在 EXE 旁边。创建快捷方式：系统设置 → 外观 → 创建桌面快捷方式；移动便携 EXE 后重新创建。

网页和桌面版不会自动共享数据。先在原环境导出 JSON，保留原备份，再在目标环境预览导入，检查正文、图片和历史。不要先清理旧站点数据。

当前 EXE 未签名，请仅从作者仓库 Releases 下载并核对 SHA-256。本地配置无额外应用层加密，请定期备份。
